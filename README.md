# PhasmoCheatV

Universal cheat for **Phasmophobia**.

This is a complete rewrite of my previous project. The codebase was redesigned from scratch to make it cleaner, easier to maintain, and more extensible.

## Status

The project is currently working with the latest supported game version.

Most features have been tested and are functioning correctly. If you encounter any bugs or unexpected behavior, feel free to report them.

## About

We are still learning C++, so this project is mainly a way for our team to practice reverse engineering, game internals, and software architecture.

The code is not perfect, and there are probably places that can be improved. Suggestions, bug reports, and pull requests are always appreciated.
